ALGO QUEST LAB (WebApp v2.0) - https://algoquest.frankjuchim.de - SO FUNKTIONIERT ES
- Schueler melden sich selbst an: Kurscode + Name (Vorname + Initial) -> persoenlicher Code (notieren!).
  Weiterspielen auf jedem Geraet mit Kurscode + Name + Code.
- Weltkarte Welt 0-6 mit 36 Lab-Leveln passend zu den ABs (283 automatisch gepruefte Aufgaben: Lueckentexte,
  Trace-/Rekursionstabellen, Struktogramme, Bug-Hunts, Code-Puzzles, Stapel/Schlange/DynArray, Baeume, Sortierschritte ...),
  Trainingsplatz mit Zufallsaufgaben, Online-Boss je Welt (Zeitlimit), Warm-up-Trainer.
- Punkte, Raenge und Abzeichen entstehen AUTOMATISCH - die Lehrkraft traegt nichts ein. Scoreboard im Kurs, optional Beamer-Board.
- Lehrkraft-Bereich (/lehrer): Kurs anlegen (Kurscode + QR), Einstellungen (Welten/Bosse freischalten, Scoreboard an/aus,
  Anmeldung offen), Schueler umbenennen/loeschen/Code anzeigen, alle loeschen, Auswertung (Fortschrittsmatrix,
  Aufgabenstatistik, Fallen-Profil P1-P10, CSV), Aufgaben-Vorschau mit Loesungen, Urkunden.
- Weitere Lehrkraefte registrieren sich selbst; der Superadmin (ADMIN_EMAIL/ADMIN_PASSWORD) schaltet sie frei.
- Online-IDE bleibt extern (Geruest-Dateien); die Lab-Level zeigen das passende IDE-Level als Hinweis.

INSTALLATION AUF CAPROVER (Details im README)
1. Neue App anlegen, HTTP-Port 80, "Has Persistent Data" aktivieren, Persistent Directory /app/data.
2. Umgebungsvariablen: ADMIN_EMAIL (= Benutzername des Superadmins; ohne Angabe "admin"), ADMIN_PASSWORD (mind. 10 Zeichen, besser 12+),
   SESSION_SECRET (lange Zufallszeichenkette, z. B. openssl rand -hex 32).
3. Deployment -> "Upload tar file" -> algoquest-webapp.tar. Domain algoquest.frankjuchim.de verbinden, HTTPS aktivieren.
4. Anmelden unter https://algoquest.frankjuchim.de/lehrer, Kurs anlegen, QR-Code/Kurscode an die Klasse geben.

VOR DEM ERSTEN EINSATZ PRUEFEN
- Datenschutzseite des Lab (/datenschutz, Datei public/datenschutz.html) an die Schule anpassen.
- Online-IDE: Bibliothek "Niedersachsen" aktivieren (Workspace rechtsklicken -> Einstellungen -> Haekchen);
  Stack/Queue/DynArray/BinTree sind dort NICHT generisch (Casts, z. B. (Integer) s.pop()). Gerueste einmal in der echten
  Online-IDE laufen lassen (geprueft wurde mit javac + Nachbau der Bibliothek): assertEquals mit Kommazahlen,
  BinTree auf leeren Baeumen, destroy() auf Text im Baumzeichner, for-each ueber DynArray.
- Die Online-IDE vergleicht Zeichenketten mit == inhaltlich: Tests erkennen "== statt equals" dort nicht (Code-Review).
- QR-Code zur YouTube-Playlist eintragen. Notenschluessel in den Klausur-Erwartungshorizonten an die Schulvorgabe anpassen.
